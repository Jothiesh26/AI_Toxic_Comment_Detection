Architecture Overview

⚙️ Dual-Stage Hybrid Engine

How Finite State Automata and Contextual Transformers collaborate to detect toxicity.

01 O(N) Match

Aho-Corasick DFA

Constructs a deterministic finite-state automaton with keyword failure links. Scans input text in linear time to immediately catch known abusive phrases.

02 Deep NLP

Toxic-BERT Classifier

Leverages a pretrained transformer to inspect nuanced semantics, toxic context, and implicit harassment across multiple toxicity sub-categories.

03 Synthesis

Hybrid Decision Rule

Merges deterministic pattern hit verification with model confidence thresholds, providing high sensitivity and transparent explainability.
